# xiaozhou-tan.github.io

Personal site for Xiaozhou (Leo) Tan — data scientist, London.
Live at <https://xiaozhou-tan.github.io>.

One self-contained `index.html`: no build step, no framework, no dependencies
beyond Inter from Google Fonts. The background is a WebGL fragment shader whose
rate is modulated by scroll velocity, with a CSS gradient fallback where WebGL
is unavailable.
